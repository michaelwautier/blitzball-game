# Blitzball

A browser-playable recreation of the Blitzball minigame from Final Fantasy X.
Personal fan project — not affiliated with Square Enix.

Real-time swimming in a top-down 2D sphere pool, with the classic pause-and-menu
encounters (Breakthrough / Pass / Shoot) resolved by stat-vs-stat rolls, techniques,
player leveling, and a 6-team league with recruiting.

See [PLAN.md](PLAN.md) for the full design and phased roadmap.

## Stack

Vite + TypeScript + Canvas. Deterministic simulation core, rendering and menus on top.

## Development

```sh
npm install
npm run dev
```
